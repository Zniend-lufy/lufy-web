# Cómo contribuir

1. Abre un *issue* o un *pull request*. Explica qué cambia y por qué.
2. Solo fuentes públicas y oficiales. Cada cifra lleva su fuente (institución, documento, fecha).
3. Cada hallazgo usa una de cuatro etiquetas: CONFIRMADO, INDICIO, ABIERTO o HIPÓTESIS.
4. No se asignan culpas. Se evalúan contratos y documentos, nunca personas.
5. Prohibido subir cédulas, teléfonos, correos personales o fotos de personas.
6. Una noticia no es el documento: enlaza o archiva el documento original.
7. Los tests usan solo datos inventados.
8. Al contribuir aceptas que tu código se publique bajo AGPL-3.0 y tus datos/textos bajo CC BY 4.0.
