# Seguridad

- No abras un issue público para reportar una vulnerabilidad o un dato personal expuesto.
- Usa "Report a vulnerability" (GitHub Security Advisories) de este repositorio.
- Si encuentras una cédula, teléfono, correo personal o foto de una persona, repórtalo por esa vía y se retirará.
- Las claves y tokens van solo en variables de entorno (ver `.env.example`), nunca en el código.
