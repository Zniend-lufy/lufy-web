# Lufy — LÉEME

Lufy ordena datos públicos del Ecuador y los verifica contra el documento original.
No acusa a nadie. Señala contratos y cifras, nunca juzga personas.

## Las cuatro etiquetas

- **CONFIRMADO**: lo dice un documento oficial que se puede revisar.
- **INDICIO**: hay datos que apuntan a algo, pero falta el documento que lo cierre.
- **ABIERTO**: no hay documento todavía; la cifra o el dato no se da por cierto.
- **HIPÓTESIS**: sirve para saber dónde mirar. No sirve para concluir.

Una noticia no es el documento. Si no se puede verificar, no se inventa.
